# Monelis — kurulum dosyaları

Bu depo yalnızca **Monelis kurulum dosyalarını** barındırır.

En son sürümü **[Sürümler (Releases)](../../releases/latest)** sayfasından indirebilirsiniz:

| Dosya | Bilgisayar |
|---|---|
| `Monelis-windows.zip` | Windows 10/11 (64 bit) |
| `Monelis-mac-arm64.tar.gz` | Mac — Apple Silicon (M1, M2, M3 …) |
| `Monelis-mac-x64.tar.gz` | Mac — Intel |

**Windows:** zip'i bir klasöre çıkarın, `Monelis\Monelis.exe`'ye çift tıklayın. İlk açılışta "Windows bilgisayarınızı korudu" uyarısı çıkarsa **Ek bilgi → Yine de çalıştır**.

**Mac:** `Monelis.app`'i Uygulamalar klasörüne sürükleyin. İlk açılışta uyarı çıkarsa uygulamaya sağ tıklayıp **Aç** deyin.

Verileriniz yalnızca kendi bilgisayarınızda, şifreli olarak saklanır.
